## Добавление реквизита на форму: сводная информация о ставках НДС в шапке документа
Бывают поставки с разносортной номенклатурой. В связи с этим в одном документе может быть несколько ставок НДС. Заказчик для удобства анализа просит добавить сводную информацию, как ниже на картинке:
<img src=img/nds.png width=900>
<br/>
Для реализации использовано расширение. Мы добавили реквизит в Документ, вывели его на форму:
<details>
<summary>Как в новый реквизит попадает значение?</summary>
<br/>
Реквизит СтавкиНДС заполняется в процедуре ПодготовитьФормуНаСервере. Она включена в расширение, сделаны вставки:
   
```
     &НаСервере
     &ИзменениеИКонтроль("ПодготовитьФормуНаСервере")
     Процедура Расш1_ПодготовитьФормуНаСервере()
     …
     	 #Вставка 
     	//+ добавление гиперссылки Ставки НДС
     	СтавкиНДС = Расш1_ЗаполнитьСтавкиНДС(Объект.Ссылка);
     	//- добавление гиперссылки Ставки НДС
     	#КонецВставки
     
     КонецПроцедуры  
     
```
<br/>
Гиперссылка появится, если после записи/проведения документа перезайти в форму.
<br/>
Функция по заполнению значения:

```

                       |	ПоступлениеТоваровУслугТовары.СтавкаНДС КАК СтавкаНДС
                       |ИЗ
                       |	Документ.ПоступлениеТоваровУслуг.Товары КАК ПоступлениеТоваровУслугТовары
                       |ГДЕ
                       |	ПоступлениеТоваровУслугТовары.Ссылка = &Ссылка" ;
Результат = Запрос.Выполнить();
Если НЕ Результат.Пустой() Тогда
	МассивСтавокНДС = Результат.Выгрузить().ВыгрузитьКолонку("СтавкаНДС");
	Возврат СтрСоединить(МассивСтавокНДС, ", ");

```
</details>

## Новый отчет с помощью расширения
<br/>
Требуется отчет, где видно расход денежных средств по статьям, контрагентам, договорам. При этом важно ещё видеть ответственного за статью, так устроен порядок у заказчика. То есть за каждой статьей движения денежных средств закреплен ответственный. 
<br/>
В типовой конфигурации есть подобный отчет: Анализ движений денежных средств. 
<br>Но он нам не подходит, так как нас интересуют только списания. А также нужен новый реквизит, который заказчик хочет видеть на форме (поэтому с помощью дополнительных сведений реализовать нельзя).
<br/>
<br/>
1) Создадим реквизит на форме элемента справочника Статьи движения денежных средств
<br/>
<img src=img/otvetstvennyj.png width=900>
<br/>
2) Разработаем оборотный регистр, регистраторами будут выступать Списание с расчетного счета и Расходный кассовый ордер
<br/>
<img src=img/registr.png width=900>
<br/>
3) Настроим движения регистраторов. Нужно внести изменения в модуль менеджера и в модуль объекта
