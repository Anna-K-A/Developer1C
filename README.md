# Создаем новую печатную форму
Мы получили запрос от пользователя на создание печатной формы. Какой план действий?
1) Найти наиболее похожий макет в типовой конфигурации
<details>
<summary>Как это сделать?</summary>
В помощь идёт знание типовой конфигурации в пользовательском режиме (спасибо опыту работы бухгалтером/консультантом).
<br>Если заказчик просит форму для конкретного документа, скорее всего там и надо искать похожую форму.
<br>В нашем случае требуется разработать форму для списания бракованных материалов (для образца дали пример из интернета - бумажная версия).
<br>Значит искать будет в документе Требование-накладная. Из этого документа можно вывести несколько печатных форм. В том числе Акт на списание материалов.
<br>Этот макет мы и будем использовать за основу.
